01 / BROWSER PROTECTION USERSCRIPT v10.4.1.8 · Active (MIT)

Nvirya AdGuard

A lightweight, mobile-first browser protection and navigation security userscript built for Safari (Stay, Userscripts) and desktop script managers (Tampermonkey, Violentmonkey). Injected at document-start across all frames to neutralize intrusive popunders, click-hijacking listeners, and malicious redirects before they execute.

  • [01] Pop-up & Redirect Shield: Wraps window.open, location.assign/replace, and history state mutations to block blank-tab redirects and nested ad URLs.
  • [02] Media-Safe Cosmetic Filtering: Cleans ad slots, floating banners, and high-z-index invisible overlays while strictly protecting <video>, JWPlayer, Video.js, and Plyr controls.
  • [03] Shadow DOM Action Sheet & Element Picker: Isolated mobile-native control panel with per-domain whitelisting, rule import/export, and interactive on-page element selection.

Nvirya AdGuard v10.4 — Runtime Interception & Storage Architecture

Executes before host page scripts to wrap navigation APIs, guard media players against false-positive removal, and isolate its mobile action sheet inside a closed/open Shadow DOM boundary.

nvirya-adguard.user.js (v10.3.0 / v10.4.1.8) 
// ==UserScript==
// @name         Nvirya AdGuard
// @namespace    https://nvirya.com/adguard
// @version      10.4.1.8
// @match        *://*/*
// @run-at       document-start
// @all-frames   true
// ==/UserScript==

const DEFAULT_CONFIG = {
  version: 3,
  enabled: true,
  popupProtection: true,      // Hooks window.open & synthetic click-hijacks
  redirectProtection: true,   // Guards location.assign/replace & nested ad URLs
  cosmeticFiltering: true,    // MutationObserver + selector pruning
  playerProtection: true,     // Preserves <video>, JWPlayer, Video.js, Plyr
  antiAdblock: true,          // Neutralizes overlay walls & scroll locks
  strictMode: false,
  elementPicker: true,        // Interactive Shadow DOM element selector
  edgeHandle: true,
  theme: 'auto'               // 'auto' | 'light' | 'dark'
};

03 — ABOUT & ENGINEERING APPROACH

INDEPENDENT SOFTWARE ENGINEERING
IDENTITY · NVIRYA (@ME)

Practical systems built close to the browser runtime.

Nvirya is an independent developer focused on building software that operates reliably in hostile or complex web environments—ranging from document-start browser protection scripts and Shadow DOM interfaces to unified AI workspaces and asynchronous Python/FastAPI service backends.

Rather than relying on heavy abstraction layers, each project prioritizes direct DOM and network primitives, predictable state persistence, and responsive ergonomics across both mobile Safari and desktop browsers.

01 / RUNTIME DISCIPLINE

Zero-Bloat Execution

Browser tools and userscripts must initialize in milliseconds at document-start without degrading host page frame rates or layout stability.

02 / DEFENSIVE DOM ENGINEERING

Preserve Core Media & UX

Aggressive ad and popup interception is paired with explicit node guards so legitimate HTML5 <video>, JWPlayer, and Video.js controls never break.

03 / STYLE ISOLATION

Shadow DOM Boundaries

Injected controls and mobile action sheets are encapsulated inside Shadow DOM roots so host CSS cannot bleed into or distort tool interfaces.

04 / CLARITY OVER DECORATION

Intentional Interfaces

Interfaces are structured around high-contrast typography, semantic theme tokens, keyboard accessibility, and clear operational feedback.
